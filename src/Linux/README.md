# Linux

操作系统层的原理与实战：内核机制（命名空间、cgroups）、进程与 /proc、权限体系、排障工具链；以及常挂在 Linux 上的 Web 入口 **Nginx**。

容器时代很多「玄学问题」，根子都在 Linux 内核——这个板块从具体工具切入，往下挖到系统层。读 Docker 网络前若卡在「地址池 / 网段 / 网关」，可先看基础篇 [《IP、网段与网关》](/Linux/basics/linux-02-ip-subnet-gateway)。Nginx 系列则从 Ubuntu 本机安装、反代与负载均衡入手，兼顾事件模型与生产性能清单。
