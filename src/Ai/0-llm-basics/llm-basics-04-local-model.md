## 一、本文要解决的问题

参数量、量化、上下文长度怎么影响一台笔记本上的体验？本地小模型和云端大模型的差距到底在哪、什么时候够用？亲手跑一遍，模型从「云端的黑盒」变成「磁盘上的文件」。

## 二、知识点清单

- Ollama 的模型管理：pull / run / Modelfile
- 参数量与显存需求的粗略换算（fp16 下每参数约 2 字节）
- 量化：Q4/Q8 拿精度换显存，质量损失直觉
- 本地 vs 云端：隐私、成本、延迟、能力四个维度的分工

## 三、动手实验（学习时必须真跑）

- Ollama 跑 qwen3 小模型（如 4b/8b），与商用 API 同题对比 10 个问题
- 同一模型跑两个量化档位，对比质量与速度
