## 一、本文要解决的问题

怎么知道自己真的出师了？闭卷自测是唯一的诚实答案。30 问覆盖全部十阶段，每题都要求「讲给同事听」的水平——答不出的题，回到对应篇目重学，直到 30 问全清。

## 二、知识点清单

- 十阶段各三问：度量（QPS 推导 / Little 定律 / 三笔账）、接入（扩容路径 / LB 算法 / 线程模型）
- 缓存（三兄弟对策 / 一致性窗口 / 热点多级）、消息（削峰数学 / 存储三快 / 堆积应急）
- 分片（拆前穷尽 / 基因法 / 扩容 runbook）、防护（四板斧分工 / 四算法曲线 / 规则落地）
- 高可用（9 的预算 / 切换三问 / 双活多活差异）、场景（IM 投递 / Feed 推拉 / 推送容量）、验证（压测盲区 / 影子路由 / 水位目标）
- 自测方法：闭卷作答 → 录音回放自审（能否脱稿讲清）→ 盲区回补 → 一周后复测

## 三、动手实验（学习时必须真跑）

- 第一次闭卷自测，记录得分与每题的卡壳点
- 对每个盲区回到对应篇目重学，补齐后复测
- 间隔一周再做一次全清验证（对抗遗忘曲线）

## 四、验收标准（全部通过才进入下一篇）

- [ ] 25 / 30 以上：资深达标
- [ ] 30 / 30：出师，可以带人做架构评审
- [ ] 每道答不出的题都能定位到对应篇目

## 五、阶段验收（本篇是阶段 9收尾篇）
