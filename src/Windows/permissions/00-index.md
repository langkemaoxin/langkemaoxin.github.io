# 索引：一步步「发明」Windows 权限

> 假设世界上本来没有「权限」这回事。  
> 我们不从名词大全开始，而用**西蒙/费曼式**读法：  
> **一次只讲透一个概念 → 只用已经会的东西解释它 → 讲完再往前走，尽量不剧透后面。**

每一站固定节奏：**案例引入麻烦 → 西蒙式只发明一个概念 → 怎么看见（命令或界面）→ 你现在会了什么。**  
专有名词尽量后置。关键论断旁标注 Microsoft Learn 出处。

本页是**全局导航**：先看「这一站干什么」，再点进对应章节。不必一次读完。
