# 微信小程序

两条线一起看：

1. **基础篇（14）**：双线程、页面四件套、setData、事件、路由、生命周期、WXS、组件、API、Skyline、分包、发布。实验仓：[mp-demo-lab2](https://github.com/code-corey/mp-demo-lab2)  
2. **实战篇（5）**：从 0 做最简 TodoList（添加 / 完成 / 删除 / Storage）。成品仓：[mp-todolist](https://github.com/code-corey/mp-todolist)

建议顺序：先扫基础篇建立心智，再按实战篇跟做一个能用的小程序；也可边做实战边回基础篇查原理。
