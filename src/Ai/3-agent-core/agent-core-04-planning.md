## 一、本文要解决的问题

长任务交给 Agent，是让它先列计划再执行，还是走一步看一步？两种模式各有翻车姿势：计划过时 vs 陷入局部循环。

## 二、知识点清单

- plan-and-execute：先产出任务分解，再逐步执行，可人工审计划
- 反馈式（ReAct 系）：边执行边修正，灵活但易跑偏
- 任务分解的质量：分解粒度、依赖表达、可验证子目标
- 重规划：执行中发现计划失效怎么办

## 三、动手实验（学习时必须真跑）

- 同一长任务（如「调研一个技术并写报告」）分别用两种模式实现，记录完成度与轨迹
- 故意在环境中设一个意外（文件已存在 / 接口报错），看两种模式的应对
