# 软件架构

本专栏从 **DDD（领域驱动设计）** 切入软件架构：先讲清为什么要摆脱事务脚本与贫血 MVC，再走战略建模与战术分层，最后落到 COLA、Repository、防腐层等可落地实践。

素材整合自两份互补课件：体系化「DDD 学习圣经」与阿里实践向的领域设计规范。建议按侧栏顺序阅读。

## 系列分组

- **入门与动机**：价值、流程痛点、SOLID/OO 基础
- **战略设计**：限界上下文、拆分原则、建模方法、事件风暴
- **战术与分层**：四种模型、Domain Primitive、六边形、Repository、领域/应用/接口层
- **落地实践**：COLA 脚手架、防腐层与复盘
