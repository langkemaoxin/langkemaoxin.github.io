## 一、本文要解决的问题

一个 Agent 顶不住复杂任务时，是给它一个「上级」还是给它一群「同事」？编排（图 / 状态机）与协同（蜂群）是多智能体的两条路线——AICon「蜂群智能」专题的技术底座。

## 二、知识点清单

- 为什么需要多智能体：上下文隔离、角色分工、并行
- 编排式：图编排（LangGraph 类），节点即步骤，确定性拓扑
- 协同式：swarm / 蜂群，角色间移交（handoff），涌现式协作
- 通信成本与一致性：消息传递、共享状态、结果汇聚
- EvoMap「自进化蜂群：让 Agent 继承经验」在解决什么

## 三、动手实验（学习时必须真跑）

- 用图编排实现一个两角色流水线（如「研究员写初稿 + 审校改稿」）
- 精读 AICon《从固定编排到自进化蜂群：EvoMap 如何让 Agent 继承经验》议题摘要，与自己的流水线对照差距
