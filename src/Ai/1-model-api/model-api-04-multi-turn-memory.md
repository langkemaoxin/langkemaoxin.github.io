## 一、本文要解决的问题

模型本身无状态，为什么聊天像「记得」你？因为每一轮都在重发全部历史。理解这一点，才能理解记忆的几种形态与它们的成本。

## 二、知识点清单

- messages 数组：多轮的本质是历史重拼
- token 随轮数累积：多轮对话越来越贵的账
- 记忆三形态：全文重发 / 滚动窗口 / 摘要压缩（外存向量库在阶段 2 展开）
- 「记得」的错觉：截断窗口后模型为何装作无事发生

## 三、动手实验（学习时必须真跑）

- 手动维护 messages 实现一个命令行多轮对话
- 对话 20 轮后打印完整请求体，直观看 token 膨胀；再实现滑动窗口版对比
