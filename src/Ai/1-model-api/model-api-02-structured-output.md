## 一、本文要解决的问题

模型输出的是自然语言，程序要的是结构。怎么让输出稳定可解析？为什么说 Agent 的一切都建立在结构化输出上？

## 二、知识点清单

- JSON mode 与 JSON Schema 约束输出的原理（解码层约束 vs 提示层请求）
- schema 设计：枚举、嵌套、required 的取舍
- 解析失败的兜底：重试、修复、降级
- 「概率采样 × 硬约束」的边界：什么时候还是会出错

## 三、动手实验（学习时必须真跑）

- 用 schema 约束一个「从文本抽取结构化字段」任务；先故意要求散文输出看错误率，再看约束如何纠正
- 构造一个 schema 也救不了的边缘输入，观察失败模式
