## 一、本文要解决的问题

技术之外，AICon 用好几个专题讨论组织与生意：超级个体（一人 + Agent 军团）、蜂群组织（Agent 协同的分工）、Agentic 增长（用 Agent 撑起超线性扩张）。概念级了解，建立「技术如何变成钱」的翻译能力。

## 二、知识点清单

- 超级个体：Agent 放大个体产能的机制与边界（哪些岗位先被放大）
- 蜂群组织：从固定编排到自进化协同；人机混合团队的管理界面
- Agentic 增长：Zilliz 案例——Agent 支撑超线性扩张的含义（人效比）
- 高价值场景的共性：金融 / 电商 / 分销场景中 Agent 的 ROI 账
- 判断框架：什么业务适合「Agent 化」（高频 / 有规则 / 容错可补偿）

## 三、动手实验（学习时必须真跑）

- 精读三场议题摘要：《Zilliz Agentic-Native 增长》《快手分销增长 Agent》《从超级顾问到 Agent 蜂群》
- 各用三句话总结：谁的什么问题、用什么解法、换来了什么
