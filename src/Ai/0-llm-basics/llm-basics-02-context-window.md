## 一、本文要解决的问题

上下文窗口是什么？为什么 10 万 token 的上下文又贵又慢？注意力机制让模型对前文「记账」（KV cache），这份账随长度增长——这是将来听懂一切推理优化议题（vLLM、SGLang、长上下文）的物理基础。

## 二、知识点清单

- 上下文窗口的定义：输入 + 输出共享一个窗口，超了就截断
- 注意力直觉（一句话版）：每个 token 回看所有前文、按相关性加权
- KV cache：前文记一遍账、生成时反复查——为什么它随长度线性膨胀、为什么吃显存
- 大海捞针（NIAH）测试：长上下文能力的标准考题
- 「记住」≠「用得上」：中间信息被忽视的 lost-in-the-middle 现象

## 三、动手实验（学习时必须真跑）

- 给同一问题垫 0 / 1k / 10k token 前缀，分别测延迟与 token 计费，做成表格
- 在 10k 前缀中间藏一个关键事实（大海捞针），测试模型能否找到
