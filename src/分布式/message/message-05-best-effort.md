## 一、本文要解决的问题

支付回调为什么「尽力就行」？衰减重试、查证接口、对账文件三层防线各自兜什么底？

## 二、知识点清单

- 跨企业通知的一致性责任划分：通知方尽力，被通知方负责查证
- 衰减重试间隔表设计（如 1m / 5m / 10m / 30m / 1h）
- 查证接口：被通知方主动查询的兜底通道
- 对账文件：最终的对账防线
