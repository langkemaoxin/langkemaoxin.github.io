## 一、本文要解决的问题

大模型的输出怎么来的？为什么同一个问题每次答案不一样？为什么会一本正经地胡说八道？这是全部 AI 知识的地基——把「模型 = 下一个 token 的概率采样器」变成直觉，后面一切（温度、幻觉、上下文、Agent）都建立在这句话上。

## 二、知识点清单

- 自回归生成：模型每次只预测下一个 token，再把预测拼回输入滚动前进
- token 与 tokenizer：为什么中文更费 token、代码为什么特殊
- 概率分布与采样策略：greedy / temperature / top-p 各自改变什么
- 幻觉的机制根源：模型优化的是「像不像人话」不是「真不真」——幻觉是必然副产品，不是 bug
- 为什么 temperature=0 也不完全可复现（浮点并行等因素，了解即可）

## 三、动手实验（学习时必须真跑）

- 裸调 API（Python requests 或 curl）：同一问题 temperature=0 连跑 10 次，记录输出差异
- temperature 调 1.5 再跑 10 次，观察输出如何发散
- 问一个模型不知道的冷门事实，观察它如何「流畅地编」

## 四、验收标准（全部通过才进入下一篇）

- [ ] 能用一段话向外行解释「模型为什么会胡说八道」，且不带未解释的术语
- [ ] 能说清 temperature 调的是「采样的随机性」而不是「模型的聪明程度」
