# Corey 知识库

本站已从 Jekyll/Hux **整站迁移**到 [VuePress Theme Hope](https://theme-hope.vuejs.press/zh/)。

- 在线：https://www.code-corey.com
- 本地：`pnpm install && pnpm docs:dev`
- 构建：`pnpm docs:build`
- 旧站备份分支：`archive/jekyll-hux`
- 旧文件目录：`_legacy-jekyll/`（可稍后删除）

GitHub Pages 通过 Actions 部署到 `gh-pages` 分支。请在仓库 Settings → Pages 将 Source 设为 **Deploy from a branch → gh-pages / root**（或 GitHub Actions，若改用官方 Pages action）。
