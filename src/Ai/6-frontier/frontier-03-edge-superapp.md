## 一、本文要解决的问题

手机上真跑得动大模型？端侧管即时感知与隐私、云端管复杂推理——端云协同是端侧智能的主形态。而超级 App 的「AI 原生化」，本质是把 UI 从按钮入口改成对话与意图入口。

## 二、知识点清单

- 端侧模型的档位：1-3b 量化模型 + NPU 加速；手机内存与功耗约束
- 端云协同路由：简单请求留端上、复杂任务上云、敏感数据不出端
- 端侧行为感知：输入法、截屏、传感器作为上下文来源
- Agentic UI / GUI Agent：从按钮 UI 到意图 UI（支付宝 xUI 的终端交互引擎）
- 系统级融合：鸿蒙 AI Native 的系统层 Agent 思路
