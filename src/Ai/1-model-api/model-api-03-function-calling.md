## 一、本文要解决的问题

模型怎么「调用」你的函数？这一步是 Agent 的原子操作——不用任何框架，裸 HTTP 手写一遍 50 行的循环，Agent 就从神秘词汇降级为 while 循环。

## 二、知识点清单

- 工具定义三要素：name / description / parameters（JSON Schema）
- 消息流：模型返回 tool_call → 程序执行 → tool result 回填 → 模型继续
- 模型侧「决定调用」与程序侧「执行」的分工（模型从不执行任何东西）
- 并行工具调用与多轮工具链；工具定义占上下文的 token 成本

## 三、动手实验（学习时必须真跑）

- 不用框架，裸 HTTP 实现「查天气 + 计算」两工具的调用循环（约 50 行）
- 加第三个工具，故意给模糊指令，观察模型怎么选、选错怎么办
