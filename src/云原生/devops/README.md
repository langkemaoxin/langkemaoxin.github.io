# DevOps / GitOps

从 DevOps 文化与 CI 工具链，到 GitOps（Argo CD）持续交付。建议按序号阅读；CI 三条路径（Jenkins / GitHub Actions / GitLab CI）可对照学。

## 怎么读

1. **01–02**：先建立「为什么」与 GitOps 心智模型  
2. **03–07**：把仓库 → 构建 → 质量门禁 → 镜像制品串起来  
3. **08–11**：搭环境、装 Argo CD、准备应用仓库  
4. **12–14**：三条 CI 分别对接 Argo CD 的端到端发布  
5. **15**：多集群与回滚
